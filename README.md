🔹 fitoclin & confirme
Plataforma avançada de CRM, PEP (Prontuário Eletrônico) e Gestão Clínica multimódulo.

AI & Automation: Orquestração de assistentes inteligentes via n8n e Redis para gerenciamento de memória contextual, automação completa de agendamentos via WhatsApp, rotinas de triagem e transcrição automatizada de consultas.

🔹 make-marketplace
Arquitetura robusta de marketplace ponta a ponta focado em escalabilidade e conversão.

Core: Controle de estado avançado, roteamento dinâmico otimizado, relatórios de analytics integrados nativamente e split de pagamentos complexos estruturados com Stripe API e Webhooks de alta confiabilidade.
